# Coffee Shop Network Infrastructure Project

---

# Project Overview

This repository documents a fictional — but realistic — end-to-end networking project created to gain practical, hands-on experience while studying for the CCNA.

The project simulates the:
- Design
- Deployment
- Services & Security
- Automation & Programability
- Troubleshooting & Optimization
- Support & Maintenance

of a coffee shop network infrastructure using real-world networking concepts, tools, and configurations.

---

# Project Goals

The primary objective of this project is to reinforce CCNA concepts through:
- Practical labs
- Real-world scenarios
- Infrastructure design
- Operational troubleshooting

The project is designed to simulate how networking environments are planned, deployed, secured, maintained, and supported in production environments.

---

# Project Scope

This project covers multiple areas of networking, including:

| Area | Description |
|---|---|
| Network Design | Topology planning, VLAN design, IP addressing, redundancy |
| Network Implementation | Switch/router configuration and deployment |
| Network Services & Security | DHCP, NAT, ACLs, port security, secure segmentation |
| Network Automation & Programmability | Basic automation and network management concepts |
| Network Troubleshooting & Optimization | Connectivity testing, verification, and issue resolution |
| Infrastructure Support & Maintenance | Operational support and monitoring workflows |
| Documentation & Project Closeout | Network documentation and project organization |

---

# Technologies & Concepts

Some of the networking concepts used throughout this project include:

- Assesment of current network infraestructure and identification of required improvements
- Implementation of IPv4 and IPv6 addressing, routing protocols and VLANs
- Interswitch connectivity and Layer 2 / Layer 3 Etherchannels
- Implementation of network security measures, including access control lists and Layer 2 security features
- Integration of network services, such as STP, NAT, DHCP, DNS and NTP
- Installation and configuration of Wireless infraestructure, including APs and Controllers 
- Ongoing monitoring, support and maintenance services for network infraestructure
- Automation and programmability to deploy networks when possible

Rather than only studying theory, the goal is to:

- Configure devices
- Validate connectivity
- Troubleshoot failures
- Document findings
- Think operationally

This mirrors how networking is performed in real production environments.
